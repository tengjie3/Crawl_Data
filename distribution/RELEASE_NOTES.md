# 智能找数 · 免安装 HTML 离线版

285 个数据集、855,000 条完整记录、86 份独立画像报告、3 份领域报告。支持实际样本预览、筛选、数据集对比和浏览器内合并下载。

## 下载方法

1. 下载 **三个 `.zip.part01` / `.zip.part02` / `.zip.part03` 分卷** 和 `download-helpers.zip`，放在同一目录。
2. 将 `download-helpers.zip` 解压到分卷旁边。Windows 双击 `join-windows.cmd`；macOS/Linux 运行 `sh join-macos-linux.command`。
3. 合并脚本自动校验 SHA256。校验通过后解压完整 ZIP，用 Chrome/Edge 打开其中 `index.html`。

**网页不需要 Python、Node、后台服务器或联网。不要下载 GitHub 的 Source code (zip) 作为完整网页包，它不含大型数据资源。**

三个分卷合计 4,063,391,415 Byte；解压后约 5.76 GB。下载、拼接和解压建议预留至少 15 GB 磁盘空间。
